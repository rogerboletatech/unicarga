# UniCarga

Landing page de validação da UniCarga: um saldo para carregar o carro elétrico em vários eletropostos.

Publicada com GitHub Pages a partir da branch `main`.

## Lista de espera

Os botões levam a um formulário externo. Para ligar, edite `FORM_URL` no fim do `index.html`.
Cada botão envia `?perfil=motorista` ou `?perfil=frota`.
